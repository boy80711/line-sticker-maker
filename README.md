# LINE Sticker Maker
適用 LINE Creators Market 貼圖製作工具｜純前端離線工具，GitHub Pages 線上可用
專門用於快速編輯貼圖文字、圖片清晰度調整，匯出符合LINE官方規格透明PNG

## 內建規格
- 主貼圖：960×960px 透明PNG
- 安全邊距參考線（預防審核退件）
- 支援靜態貼圖，批次匯出

## 功能列表
🎨 文字編輯
- 新增多層文字、拖曳移動、縮放、旋轉
- 文字顏色、描邊、陰影、字型大小自由調整
🖼️ 影像清晰度工具
- 銳化、亮度、對比、飽和度調整，改善手機顯示模糊問題
📦 匯出功能
- 單張匯出透明PNG
- 後續擴充：批次匯出、ZIP打包
✅ LINE審核輔助提示
- 規範提醒、安全邊框視覺參考
